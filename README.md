## Projects

### Mini Instagram

A full-stack Instagram-inspired application focused on backend CRUD operations and image management.

**Backend:**

- Node.js
- Express.js
- MongoDB
- Mongoose
- Multer
- ImageKit

**Features:**

- Create posts
- Get all posts
- Get a single post
- Update posts
- Delete posts
- Upload images
- Replace images
- Delete images from ImageKit
- Store image metadata in MongoDB

This project helped me understand how a backend handles the complete flow from an incoming request to database operations and cloud file storage.
